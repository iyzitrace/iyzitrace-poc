# Platform install

On the `mkk-poc` branch, follow the step-by-step guide at the root of the repository:
[../../README.md](../../README.md). The settings are in [values.yaml](values.yaml) (operators, object store and
platform) and [values-cert-manager.yaml](values-cert-manager.yaml); the guide tells you which words to replace.

The general guide, for any cluster and any choice of registry and proxy, is on the `main` branch.
